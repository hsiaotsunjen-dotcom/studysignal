僅使用既有單頁 API 回應及原始來源；本次 API 呼叫 0，接受或套用修改 0。原圖、OCR 與既有回應保持不變。此報告及離線工具不修改付費執行入口，也不進行其他 11 頁。

機器驗證產物：`tmp-ocr-ai-proposal-audit-xhWuPU/proposal-audit.json`。13 項建議均保留完整原始物件，另附原文定位、原始座標、來源雜湊、問題類型及待審狀態。產物含教材文字，僅供本機審核，不應直接公開提交。

## 已確認的根因

1. `scripts/lib/ocr-ai-correction-trial.mjs` 的提示要求 `original-pixel bbox`，但同檔驗證器讀取 `bbox`。這是程式介面設計不一致；模型依提示產生的欄位不能直接供驗證器使用。
2. 單頁入口使用 `json_object`，只要求 JSON 可解析，未約束欄位名稱及型別。JSON 可解析不代表契約正確。
3. 原始 OCR 長度 865 個 UTF-16 code units，模型 13 項偏移中只有第 1 項與原文相符；第 12、13 項 end 超界。無法從回應證實模型如何計算位置，不能斷言是 UTF-16 或換行計數造成。
4. 13 項 before 都在 raw OCR 中唯一出現，故可建立確定性的文字錨點。這只能修復「尋找哪段原文」的可追溯性，不證明 after 正確。
5. 矩形即使在 2107×3164 原圖範圍內，也不代表框住正確文字。部分模型框未對應視覺位置；沒有已證實的縮放或裁切轉換，禁止推測比例後自動換算。
6. 原驗證器遇第一個錯誤即停止，摘要只存通用錯誤，未保留逐項問題；候選檔也因驗證失敗未產生。模型完整回應仍保存於 response.json，資料未因此遺失。

## 統一定位格式及修正設計

新的離線 adapter 不更動舊契約或回應：

- `originalProposal`：完整模型物件，不重寫其 start/end 或座標。
- `textLocator`：exact before 錨點、所有命中位置、唯一命中時的 start/end；固定 UTF-16、end exclusive，指向原始 raw 的 SHA-256。零命中、多命中、空字串一律不可自動定位。
- `sourceLines`：對應 raw 的行數，作為人工查看輔助，不把 OCR 行次當成正確閱讀順序。
- `imageLocator`：保留原欄位名、原始 xywh、原圖尺寸、是否越界；只有單一有效別名才可轉接。若兩個欄位內容衝突則阻擋。`visualAlignmentVerified` 維持 false。
- 來源：manifest、圖片檔名及 SHA-256、raw/result/TSV 路徑與雜湊、response 路徑及雜湊、模型版本及建議 ID。
- `status=pending_human_review`、`autoApplyAllowed=false`、語義驗證 false；不因錨點或框範圍通過而變更。

下一次付費呼叫前應統一為精確 `bbox` 欄位，加入 strict JSON schema，並將來源頁 ID、原圖尺寸、固定 OCR 行／token ID 納入契約。位置由本機計算，模型只引用來源 ID，避免讓模型計算長文偏移。schema 只解決資料契約，不解決視覺或語義正確性。此次尚未修改或驗證新的付費 API 契約。

## 三方對照驗證方式

1. 左側開啟完整原圖，顯示原圖像素尺寸及印刷頁碼；候選框作為不可信標示，不能只展示框內裁切以免漏掉定位錯誤。
2. 中間顯示 immutable raw 原文，使用唯一錨點及來源行數定位，保留原始換行。TSV 的 token/框僅作 OCR 來源證據，不當成圖像 Ground Truth。
3. 右側顯示 originalProposal.before/after、理由、信心、原始錯誤偏移與新錨點，明示座標未驗證、可能刪字及公式降格。
4. 人工逐項核對「文字是否存在」「原文是否抄對」「修改是否忠實」「上下標是否保留」「是否遺失圖表或改變閱讀順序」，獨立記錄接受／拒絕／無法判定及理由。
5. 本階段提供 JSON 對照資料及此審核流程設計，未新增 GUI，也未建立人工審核結果或 Ground Truth。未通過審核者不得形成正式校正文。

## CER／WER 設計

重用 `scripts/lib/ocr-quality-metrics.mjs` 的人工作者、region ID、圖片雜湊及 reference 文字雜湊核對機制。沒有匹配人工 reference，正式數值維持 null。

同一獨立人工參考區域分別比較原始 OCR 與候選文字，使用相同分段及 tokenization：CER = 字元編輯距離／參考字元數；WER = 詞編輯距離／參考詞數。應保留替換、刪除、插入的統計及空參考特殊處理，避免只呈現總分。現有 editDistance 僅回傳總距離，錯誤分型尚需新增並測試。

現有 CER tokenizer 是 NFC 後移除空白的全部字元，不是純中文指標；純中文區域應由人工指定評估範圍。英文 WER tokenizer 會忽略部分數字／符號，不能用來驗證化學式。大小寫、全半形、空白及標點規則應預先固定並列入報告，不得選擇性正規化掩蓋錯誤。

公式另做結構化上下標、電荷、係數的逐項核對；表格、圖示及閱讀順序另外評估，CER／WER 不能代表這些結構完整性。現階段修復數、新增錯誤數、CER、WER 均 null。
