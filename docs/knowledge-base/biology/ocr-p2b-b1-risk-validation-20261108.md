# OCR P2-B B1：自動風險分類與品質檢查

日期：2026-11-08。範圍僅限既有 P2-A 十二個 ROI；沒有執行 OCR、付費 API、重辨識、文字修正、Ground Truth 確認或 Git 提交。

## 實作與可重現方式

- `scripts/ocr-quality-gate/b1.mjs`：重用 P0 共用匹配及 P1 事件分類，提供單筆分類與非同步批次迭代介面。
- `scripts/ocr-quality-gate/b1-batch.mjs`：讀取既有 P2-A 快照，驗證來源前後完整性，寫入全新輸出目錄。這個受控入口限制為十二個 ROI。
- `scripts/ocr-quality-gate/b1.test.mjs`：37 項來源、安全、分流、去重、Unicode、批次與真實資料測試。
- 本文件：公開摘要，不包含教材 OCR 原文或原圖。

輸入：`tmp-ocr-p2a-20261108-v2/dataset.json`，SHA-256 為 `c67395075a67d951a9b762725900c3369276b7e86a02794cfa5ce871c7e0db92`。使用 `openP2A()` 驗證圖片、OCR、定位檔案與快照，不以檔名推定頁碼。

```powershell
node --test scripts/ocr-quality-gate/b1.test.mjs
node scripts/ocr-quality-gate/b1-batch.mjs --dataset tmp-ocr-p2a-20261108-v2 --out tmp-ocr-p2b-b1-NEW-RUN
```

輸出目錄必須不存在，既有輸出會被拒絕。實際本輪輸出：`tmp-ocr-p2b-b1-20261108-v1/`，含十二份 `*.risk.json`、`summary.json`、`report.md`。這些本機 JSON 保留原始事件、OCR 證據與來源路徑，**不可直接當作公開 Git 備份清單**。

## 分流與證據規則

來源失配為 `SOURCE_BLOCKED`；明確執行失敗或異常字元可提出 `RETRY_RECOMMENDED`，但不執行重試。科學符號、表格、圖說、疑似缺漏、閱讀順序及對齊歧義保留 `HUMAN_REVIEW_REQUIRED`。其餘僅可列為 `SAMPLING_CANDIDATE`，仍需要人工抽樣，並非自動確認內容。

每個問題記錄類型、位置、原因、嚴重程度、建議處理方式、圖片 SHA、掃描／印刷頁碼與原有頁碼驗證狀態、ROI、引擎版本／設定及原始結果引用。位置是來源框或 ROI 包絡範圍，不宣稱逐字定位。輸入的來源已驗證旗標必須由來源驗證器提供；純分類函式不自行讀取圖片。

同範圍、同類別問題合併為覆核項目，保留所有原事件 ID、原始證據及追溯關係。文字碰到緊貼 ROI 的邊緣是幾何背景，不直接證明截字。單一幾何匹配組內，只有原始文字的空白比較、英文詞界、數字、科學符號及行數檢查均相容，才標示為比較表示差異；不修改原文，也不宣稱原圖正確。例外證據優先於背景證據，不以合併隱藏問題。
