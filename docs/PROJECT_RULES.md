## 10 Non-Negotiable Rules

### 1. Teach thinking, never dependency
StudySignal helps students become independent learners. Never replace teachers or parents. Never train students to rely on AI for answers. The goal is always: help them learn how to think.

### 2. Guide, don't answer
Ask questions before explanations. Encourage thinking first. Adapt to the student's level. Simplify when they struggle — do not dump the answer.

### 3. Learning beats finishing
Prefer long-term habits, understanding, and growth over speed, completion theater, or “just finish the homework.”

### 4. Be a patient tutor
The AI is patient. It never mocks mistakes. It celebrates progress, not scores. Tone stays warm, human, and encouraging.

### 5. Parents must understand the journey
Parents should clearly know: what was learned, what improved, what still needs practice, and what today's learning signal means. Never make parents read cold analytics.

### 6. Improve learning — or remove it
Choose the option that improves learning over adding features or decoration. If a feature or UI element does not improve learning, remove it.

### 7. Warm, calm, simple, trustworthy, human
Every experience must feel warm, calm, simple, trustworthy, and human. Never cold, overly technical, complicated, or stressful.

### 8. No tech theater
Never look like a gadget demo, game, cyberpunk UI, neon glow, or glassmorphism. Never use pure white (`#FFFFFF`) backgrounds. Prefer the quiet library desk: warm beige, soft cream, calm blue, soft shadows, large whitespace.

### 9. Mobile first, interface second
Design for phones first. Desktop is only an expansion. The interface should disappear so students can focus on learning. Large rounded corners, comfortable spacing, no dense layouts, no heavy borders.

### 10. Protect the emotional promise
Students must feel: “I want to keep learning.”  
Parents must feel: “I can trust this AI.”  
Every screen must reduce anxiety and increase focus.

## How to use this file

Before implementing, designing, or writing copy, check:

1. Does this help students think — or does it give answers away?
2. Does this improve learning — or only add features / decoration?
3. Does this keep the product warm, calm, and trustworthy?
4. Would a parent understand today's learning without explanation?

If any answer fails — stop and redesign.
