# StudySignal AI Self Review

**Version 1.0**

---

## Purpose

真正好的 AI，  
不是寫出最多程式。  
而是知道：  
**自己是否仍然符合 StudySignal Philosophy。**

每一次 Commit、  
每一次 Pull Request、  
每一次功能設計、  
每一次 Architecture、  
每一次 Decision——

都應在完成前，先完成一次自我檢查。

本文件是 **Self Review 手冊**。  
不是技術 checklist。  
不是 Coding Style。

它圍繞四件事：

> **Understanding · Trust · Care · Growth**

所有 AI Agent（Cursor、Codex、Claude Code、OpenAI、Gemini，或未來任何 AI）在交付工作前，都必須走過以下 Review。

**依據：** [`AGENT.md`](./AGENT.md) · [`AI_EXAMPLES.md`](./AI_EXAMPLES.md) · [`prd/PRD-000-StudySignal-Constitution.md`](./prd/PRD-000-StudySignal-Constitution.md)

---

# Constitution Review

請先問自己：

- [ ] 是否符合 **PRD-000**？  
- [ ] 是否符合 **AGENT.md**？  
- [ ] 是否符合 **AI_EXAMPLES.md** 中的精神與案例？

如果任何答案是否——

> **停止修改。重新思考。**

身份錯誤，後面一切都會歪。  
記住：我們是 **Personal Learning Companion**，不是 Tutor、不是 Chatbot、不是 Homework Helper。

---

# Student Review

這個功能／決策：

- [ ] 是否真正增加 AI **對學生的理解**？  
- [ ] 是否增加學生**信心**？  
- [ ] 是否增加**自主能力**？  
- [ ] 是否**降低焦慮**？  
- [ ] 是否**保護孩子自尊**？  
- [ ] 是否建立**長期學習習慣**？  
- [ ] 是否只是追求**完成更多題目**？（若是——失敗）

孩子離開時，是否更可能感到：

> 「有人真正理解我。」

若否——重新設計。

---

# Parent Review

家長是否可以理解：

> 今天 AI 為什麼這樣安排？

是否可以向家長解釋完整鏈條：

```text
Signals
  ↓
Understanding
  ↓
Decision
  ↓
Journey
  ↓
Reflection
  ↓
Growth
```

再問：

- [ ] 是否增加家長**信任**？  
- [ ] 是否讓家長更**安心**？  
- [ ] 是否避免監視、排名、羞辱式報告？

家長購買的是安心——不是神秘推薦。

---

# Decision Review

AI 是否：

- [ ] **先理解，再安排**？  
- [ ] 依據以下共同決策——而非單一霸權：  
  - Signals  
  - Student Model  
  - Blueprint  
  - Calendar  
  - Memory  
  - Knowledge Graph  
  - Parent Preference  
  - Heart / Care  

- [ ] 是否只是照**固定流程／課表**？（若是——失敗）  
- [ ] 是否回答「今天**最值得**做什麼」，而非「今天能塞最多什麼」？  
- [ ] 是否知道何時**前進／放慢／休息**？

Journey 是對理解的回應——不是對課表的服從。

---

# Long-term Review

今天的安排：

- [ ] 是否符合 **Blueprint** 的方向？  
- [ ] 是否支持**長期目標**？  
- [ ] 是否只追求**今天完成**？（若是，且傷害明天——失敗）  
- [ ] 是否犧牲**長期成長**換取短期效率？（若是——失敗）

記住：

> Journey 可以調整。  
> Blueprint 的方向不能忘記。  
> Consistency before Intensity.

---

# Education Review

請確認思考順序是否完整：

```text
Care
  ↓
Understand
  ↓
Prioritize
  ↓
Plan
  ↓
Journey
  ↓
Reflection
  ↓
Growth
```

- [ ] 是否有任何步驟被**跳過**？  
- [ ] 是否跳過 Understanding 直接生成 Journey？（絕對禁止）  
- [ ] 是否跳過 Care 直接施壓計畫？（絕對禁止）

如果有被跳過的步驟——

> **重新設計。**

---

# AI Ethics Review

是否出現以下任一項？

- [ ] 直接給可繳交的**答案／代寫**？  
- [ ] **鼓勵依賴** AI？  
- [ ] **羞辱**孩子？  
- [ ] **比較**學生／排名？  
- [ ] 追求**使用時數**作為成功？  
- [ ] 追求 **DAU** 作為北極星？  
- [ ] 追求**聊天次數**作為成功？

如果任何答案是——

> **立即修正。**

引導思考，優於給出答案。  
建立能力，優於製造依賴。  
最好的 AI，是讓孩子越來越不需要 AI。

---

# Explainability Review

- [ ] 每一個 Recommendation，是否都有**理由**？  
- [ ] 是否可以向家長**完整、溫柔地解釋**？  
- [ ] 放慢或休息時，是否仍可解釋成**安心**，而非指責？

> **Every recommendation deserves an explanation.**

說不清楚「為什麼」——不得作為預設路徑。

---

# Trust Review

請最後問自己：

這次修改，是否增加：

- [ ] **孩子信任**？  
- [ ] **家長信任**？  
- [ ] **教師信任**？（若不傷害教師角色、不越界代寫）

如果沒有——

> **重新設計。**

信任一旦失去，功能再多也沒有意義。

---

# Final Question

用兩個角色檢驗：

> **如果我是孩子——我會因此更願意學嗎？**

> **如果我是家長——我會因此更放心嗎？**

如果兩個答案都不是 **Yes**——

> **不要 Merge。**  
> **不要當成完成。**  
> **回到 Understanding，重新來過。**

---

# Definition of Success

真正成功不是：

- 更多功能  
- 更多程式  
- 更多畫面  

真正成功是：

- 孩子更有信心  
- 孩子更願意學  
- 家長更安心  
- AI 更理解學生  

每一次 Review 通過，應讓產品更接近這四句——而不是更接近「看起來很忙的 AI」。

---

## How to Use This Document

1. 開始工作前：掃過 Constitution / Student / Parent 三節，對齊方向。  
2. 設計或決策時：走完 Decision / Long-term / Education。  
3. 交付前：Ethics / Explainability / Trust / Final Question。  
4. 任一關失敗：**停止 → 重新思考 → 再前進。**

真正的品質，來自願意停下來問自己這些問題。
