# PRD-006：Learning Blueprint（成長藍圖）

> **地位：** StudySignal 對「Learning Blueprint」的產品哲學——回答：**理解孩子之後，如何設計真正屬於他的成長方向？**  
> **服從：** [`PRD-000-StudySignal-Constitution.md`](./PRD-000-StudySignal-Constitution.md) · [`AGENT.md`](../AGENT.md)  
> **哲學一致（只讀）：** PRD-001 Journey · PRD-002 Understanding · PRD-003 Signals · PRD-004 Student Model · PRD-005 Parent Trust  
> **版本：** 1.0  
> **日期：** 2026-08-05  
> **性質：** 產品哲學（Philosophy Only）— **非課表、非教材、非課程規格、非 UI、非 API、非資料庫、非程式**

---

## 本文件先回答

> **「理解孩子之後，如何設計真正屬於他的 Learning Blueprint？」**

Blueprint **不是**課表。  
**不是**教材。  
**不是**課程。

Blueprint **是**孩子未來成長的方向——  
一條屬於這一位孩子、會隨他一起演化的路。

Journey 讓今天走得動。  
Blueprint 讓今天走得**有北**。

---

## 本 PRD 做什麼／不做什麼

| 做 | 不做 |
|----|------|
| 定義 Blueprint 為何存在、如何演化 | 不排課、不列單元、不定教材目錄 |
| 定義成長先於知識堆積 | 不設計 UI、進度條規格 |
| 定義家長可理解的方向語言 | 不寫 API、資料庫、程式 |
| 定義成功是成為與方向 | 不新增功能清單 |

對齊：Growth Blueprint 是陪伴孩子的人生藍圖，不是升學計畫（PRD-000）。  
對齊：Journey 可調；Blueprint 方向不因單日放慢而丟棄（PRD-001）。  
對齊：Becoming, not being（PRD-004）· Parents see growth, not just scores（PRD-005）。

---

# §1 Why Blueprint Exists  
## 為什麼需要藍圖？

**Journey 回答今天。**  
**Blueprint 回答未來。**

今天重要。  
方向更重要。

沒有 Blueprint：

- 每天的 Journey 容易變成隨機忙碌  
- 「完成」取代「成為」  
- 家長看見活動，看不見方向  

有了 Blueprint：

- 今天的每一步能回答：這對長期哪一點有幫助？  
- 放慢與休息仍服務同一條成長弧線  
- 孩子與家長都知道：我們往哪走——即使今天步子很小  

> 今天服務長期。  
> 沒有方向的今日行程，只是消耗。

---

# §2 Growth Before Knowledge  
## 成長先於知識堆積

真正的 Blueprint，  
**不是安排知識。**  
**而是安排成長。**

知識只是其中一部分。

| Blueprint 更在意 | Blueprint 不只是 |
|------------------|------------------|
| 能力如何長出來 | 章節掃完沒有 |
| 信心、好奇、習慣、自主 | 詞彙表與題庫覆蓋率 |
| 理解與遷移 | 單次背誦表演 |
| 可持續節奏 | 知識塞滿的假進度 |

對齊：Growth before Knowledge（精神）· Confidence before Performance · Consistency before Intensity。

知識可以被放入藍圖——  
但藍圖的主詞永遠是**這個人的成長**，不是教材的目錄。

---

# §3 Every Child Has A Different Blueprint  
## 每位孩子都有不同的藍圖

**沒有標準 Blueprint。**

每位孩子都有不同的：

- 能力  
- 興趣  
- 節奏  
- 動機  
- 夢想  
- 家庭  
- Journey（每天如何被陪）  

因此 Blueprint **永遠不同**。

把所有孩子帶向同一張課表，不是公平——是忽視。  
真正的公平，是每人擁有真正屬於自己的方向。

對齊 PRD-000 Opening：每一位孩子，都有不同的能力、節奏、夢想、情緒、故事。  
對齊 PRD-003／004：Signals 追蹤變化；Model 持續理解且不固化身份。

---

# §4 Blueprint Evolves  
## 藍圖會演化——Living Blueprint

Blueprint **不固定**。

Journey 改變。  
Signals 改變。  
Student Model 改變。  

Blueprint 就應該改變。

> **Blueprint 是 Living Blueprint。  
> 不是固定計畫。**

| Living Blueprint | 固定計畫（拒絕） |
|------------------|------------------|
| 隨理解更新方向的細節與優先 | 一年前填完永不改 |
| 保留「正在成為」的空間 | 寫死「他就是往哪種人」 |
| 與 Signals／Model 對話 | 無視今天的孩子 |
| 長期北可穩定，路徑可調整 | 路徑僵化或北隨考試飄 |

單日放慢 ≠ 放棄藍圖。  
長期方向可穩；**路徑與優先必須能隨真實的孩子演化。**

---

# §5 Long-term Before Short-term  
## 長期先於短期

今天只是一天。  
Blueprint 看的是一年——  
甚至更遠的成長弧線。

**不要因為一次考試，改變真正重要的方向。**

| 長期守護 | 短期誘惑（常傷害方向） |
|----------|------------------------|
| 信心、理解、自主、可持續習慣 | 單次分數焦慮主導一切 |
| 相對過去自己的成長 | 同學排名與羞辱比較 |
| Living Blueprint 的北 | 為完課劇場改寫人生敘事 |

對齊：Long-term before Short-term（PRD-005）· Today serves the long arc（PRD-000）。

考試可以進入情境；  
考試**不得劫持**藍圖的靈魂。

---

# §6 Parents Should Understand The Blueprint  
## 家長必須能理解這張藍圖

Blueprint 必須可以被家長理解。  
不是 AI 自己知道就好。

家長應能用人話明白：

- **為什麼現在安排這個方向？**  
- **為什麼下一步是這樣？**  
- **為什麼不是另一條路？**  

對齊 Parent Trust Engine：

- Explain before Decision  
- 讓家長理解，不是要求家長相信  
- Parents should see growth, not just scores  
- Parents buy peace of mind  

無法向家長解釋的「藍圖」——只是黑箱計畫，不是值得託付的方向。

---

# §7 Blueprint Is About Becoming  
## 藍圖關乎「正在成為」

Blueprint **不回答**：

> 孩子今天會什麼。

Blueprint **回答**：

> **孩子正在成為什麼樣的人——作為學習者、作為面對困難的人、作為越來越能帶領自己的人。**

| Being（拒絕寫進藍圖） | Becoming（藍圖語言） |
|----------------------|----------------------|
| 他就是弱科生 | 他正在建立這條路上的理解與信心 |
| 他不適合某某 | 他目前需要不同節奏與鷹架 |
| 終點分數定義一切 | 自主、好奇、韌性、理解在長 |

對齊 PRD-004：The learner is always becoming.  
孩子不是標籤；孩子是一個正在成長的人。

---

# §8 Final Belief  
## 最終信念

> **真正好的教育，  
> 不是把所有孩子，帶到同一個地方。  
> 而是幫助每一位孩子，  
> 走向真正屬於自己的方向。**

Journey 讓每一步溫柔。  
Blueprint 讓每一步有方向。  
Understanding 讓方向屬於這一位。  
Trust 讓家庭敢一起走。

沒有標準終點。  
只有真正屬於他的北。

---

# §9 Success Definition  
## 成功定義

### 不是

- 完成多少課  
- 做多少題  
- 考多少分  
- 藍圖「填滿」多少格子  

### 而是

- **孩子越來越知道自己。**  
- **孩子越來越相信自己。**  
- **孩子越來越願意學習。**  
- **家長越來越看見孩子的成長方向。**  

成功的 Blueprint：  
不必把所有人送去同一個站牌——  
只要每位孩子，都走在自己的路上，並且明天還願意再走一步。

```text

        ↓

        ↓

```

Journey 可調今天。  
Blueprint 守護方向——並允許方向隨真實的成長而活著演化。

每位孩子一張活的藍圖。  
家長看得懂，才配被信任。  

真正好的教育，
