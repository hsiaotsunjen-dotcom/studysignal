# PRD-011 — Brand Experience Sprint

> **Status:** Implemented (visual / copy only)  
> **Scope:** Emotional experience — no AI, backend, database, or new features  
> **Related:** [`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md), DEC-012

## Objective

Make StudySignal feel like opening a beautiful learning journal — warm, calm, hopeful, and unforgettable.

## Emotion

| Audience | Feel |
|----------|------|
| Students | “I want to study.” |
| Parents | “My child is accompanied.” |

## Key surfaces

- **Hero:** `早安，小宇。今天的學習，我已經替你準備好了。`
- **Support:** `完成今天，就是今天最大的進步。`
- **CTA:** `開始今天的旅程`
- **Daily plan:** journey list with emoji + minutes (not percentages first)
- **AI voice:** gentle companion lines, never robotic analysis language
- **Success:** celebration moment after today’s journey

## Out of scope

New functionality, AI engines, backend, database, navigation changes.
