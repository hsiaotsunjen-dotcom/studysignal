# PRD-012 — StudySignal Brand Voice Constitution

> **Status:** Implemented  
> **Canonical doc:** [`../BRAND_VOICE.md`](../BRAND_VOICE.md)  
> **Related:** DEC-013

## Objective

StudySignal is an AI learning companion — not tutoring software or a homework checker. Every word should make students feel: **「我可以的。」**

## Core principle

Teach · Encourage · Guide · **Never judge.**

## Delivery

1. Constitution document: `docs/BRAND_VOICE.md` (10 rules).
2. Progress UI speaks journey language (`src/design-system/voice/progressVoice.ts`).
3. Atmospheres include `voiceMood` + `voiceLine` (Hope / Quiet / Concentration / Relaxation).
4. Mock AI / parent copy rewritten for Rules 1–8.

## Out of scope

New product features, AI engines, backend, database.
